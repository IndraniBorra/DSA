Two files feed this guide:

- `implement_queue_using_stacks.notes.md` — the spoken script with `[SCREEN: ...]` cues.

Frame list inside the .drawio (each is a page/tab at the bottom of draw.io):
`00 Title · 01 Empty · 02 push(1) · 03 push(2) · 04 push(3) · 05 pop→pour · 06 after pour · 07 pop→1 · 08 pop→2 · 09 Why it works · 10 Complexity · B1–B4 brute-force`

## STEP 1 — Open the storyboard in draw.io (2 min)
1. Go to **app.diagrams.net** → *Decide later* (or save to your device).
2. **File → Open From → Device** → pick `implement_queue_using_stacks.storyboard.drawio`.
3. You'll see all frames as **page tabs along the bottom**. Click through 00 → 10 to review.
4. Tweak anything (colors, text) if you like — it's fully editable.

## STEP 2 — Export frames as images (3 min)
For each frame you want to animate:
1. Click its page tab.
2. **File → Export as → PNG…**
3. Settings: **Zoom 200%**, **Transparent background = ON**, **Selection only = OFF**.
4. Name them in order: `frame_00.png`, `frame_01.png`, … so they sort correctly.

> Tip: Export the whole set once; you'll drop them into Canva as a sequence.

## STEP 3 — Build the animation in Canva Pro (15–20 min)
You have two options. **Option A is simplest and looks clean.**

### Option A — Sequenced frames (recommended)
1. New design → **Video** (1920×1080).
2. Create one **page (scene) per frame**. Drag `frame_00.png` onto scene 1, `frame_01.png` onto scene 2, etc. Center each, fill the canvas.
3. Set each scene's duration to match your narration (Canva: click the page timing / the clock icon). Rough timings:
   - Title: 3s · Empty: 2s · each push: 2s · pop→pour: 4s · after pour: 3s · pops: 2s each · Why: 8s · Complexity: 6s.
4. Between scenes add a **transition**: select the page gap → **Transitions → Dissolve** (or *Slide*), ~0.3s. This creates the "movement" feel between states.
5. Add your **voiceover**: **Uploads → record**, or record separately and drag the audio in. Trim scene durations to fit what you're saying.

### Option B — Element-level animation (more polished, more work)
1. Instead of flat PNGs, rebuild the stack in Canva using **rounded rectangles** (one per element) — or export each stack element from draw.io separately.
2. Select an element box → **Animate → Rise / Pop** for pushes, and **Animate → Breathe/Slide** to show the "pour" moving right.
3. Use Canva's **Magic Animate** on a page to auto-animate all elements consistently.
4. This is best for the single "pour" scene (05→06). For everything else, Option A frames are enough.

### The key scene — the "pour" (frames 05 → 06)
This is the money shot. Two easy ways:
- **Easy:** scene 05 (in_stack full, arrow says "pour"), then transition (Slide-left) to scene 06 (out_stack full, reversed). The transition sells the movement.
- **Nicer:** on one scene, animate three element boxes sliding from the in_stack column to the out_stack column, landing in reversed order (1 ends on top). Use **Rise + Slide** with slight delays per box.

## STEP 4 — Assemble the full video
Order of scenes (matches the script sections in the notes):
1. `00 Title`  (Hook)
2. Problem slide (make in Canva — 4 ops + example)
3. `B1–B4` brute-force pour (Brute force section)
4. `B5 Brute complexity` (states O(n) push + "Let's see the optimal solution" redirect)
5. `01→08` optimal sequence (Optimal section)
6. `09 Why it works`
7. `10 Complexity`
8. Recap slide (one-line takeaway)

Interleave with **VS Code screen-recording clips** (live coding `MyQueueBruteForce`, then `MyQueue`, running the file). Drop those recordings between the animation scenes in Canva's timeline.

## STEP 5 — Reusable series template
1. Once Episode 1 looks good, in Canva: **File → Make a copy** → rename `DSA Series — TEMPLATE`.
2. Keep: title layout, colors (blue `#dae8fc` = input, green `#d5e8d4` = output, yellow `#fff2cc` = helper), fonts, complexity-table layout, transitions.
3. For each new problem: duplicate the template, swap the diagram frames (regenerate a new `.drawio` per problem using `gen_storyboard_drawio.py` as a starting point), and re-record the voiceover.
